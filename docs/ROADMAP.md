# 진행 현황 및 향후 계획 (Roadmap)

차량 이상궤적 식별 파이프라인의 검증·개선 실험 진행 상황과 다음 단계를 정리한 문서입니다.
각 실험의 상세 결과는 [ANALYSIS.md](ANALYSIS.md) 참고.

---

## 1. 프로젝트 현황

- **베이스라인:** LSTM 오토인코더로 정상 궤적을 학습하고 재구성 오차로 이상궤적을 식별 (석사학위논문 방법론)
- **검증 환경:** macOS / Python 3.11 / CPU, 지점 11·14·17, 합성 이상 평가셋 72개 (역주행·차로횡단·급정거·지그재그)
- **현재 최고 성능:** F1 **0.69** (차로 상대 특징 + 2D 방향장 + 궤적 스무딩)
  - 논문 원방법(재구성 오차) 대비 F1 0.25 → 0.69

### 성능 변화 궤적

| 방법 | F1 | 비고 |
|---|---|---|
| LSTM-AE 재구성 오차 (논문 원방법) | 0.25 | 행동 이상 대부분 미탐지 |
| + 차로 상대 특징 + 2D 방향장 | 0.67 | 규칙 기반 점수, 역주행 83% |
| + 궤적 스무딩 (Savitzky-Golay) | **0.69** | 현재 채택 구성, 역주행 89% |

## 2. 완료된 실험 요약 (①~⑥)

| # | 실험 | 결과 | 판정 |
|---|---|---|---|
| ① | 지점별 정규화 | 지점 14 쏠림(이상 판정 100%) 해소, 지점 11 이상 첫 검출 | ✅ 채택 |
| ② | 지점별 임계값 분리 | 임계값 2.6배 격차 정량화, 지점 17 이상 첫 검출 | ✅ 채택 (한계 명시) |
| ③ | 합성 이상 평가셋 | LSTM-AE 재구성 방식의 실제 탐지 성능 노출 (F1 0.25) | ✅ 평가 기반 확립 |
| ④ | 차로 상대 특징 + 2D 방향장 | F1 0.25→0.67, 역주행 22→89%, 급정거 100% | ✅ 채택 (최대 도약) |
| ⑤ | 소실점 자동 원근 보정 | 순개선 없음 — 원거리 지터 증폭 진단 | ❌ 비채택 (부정 결과) |
| ⑥ | 입력 품질 누적 (스무딩→ROI보정→국소분산) | 스무딩만 순개선(F1 0.69), 보정·정규화는 손실 | ⚠️ 스무딩만 채택 |

**현재 권장 파이프라인:** 지점별 정규화(①) + 지점별 임계값(②) + 차로 상대 특징·2D 방향장(④) + 궤적 스무딩(⑥ Step1)

## 3. 핵심 교훈

1. **재구성 오차 방식의 한계** — 오토인코더는 판별적 특징을 넣어도 재구성 오차로 증폭하지 못함(과잉일반화). 도메인 지식 기반 규칙 점수가 훨씬 효과적이었음. → **하이브리드(규칙+학습) 구조**가 실용적 방향.
2. **정량 평가가 없으면 개선을 판정할 수 없다** — "상위 5% 시각화"로는 그럴듯해 보이던 파이프라인이, 라벨 기반 평가에서 F1 0.25로 드러남. 합성 평가셋 도입이 이후 모든 개선의 기준점.
3. **원근 왜곡은 자동 보정으로 풀리지 않는다** — 소실점 추정 자체는 정확했으나(잔차 11~25px), 보정이 추적 지터를 함께 증폭. 실측 대응점 기반 호모그래피가 필요.
4. **저비용 개선을 먼저** — 스무딩 같은 전처리는 비용 없이 F1을 올림. 복잡한 기하 보정보다 우선.

## 4. 향후 진행 계획

우선순위 순. 각 항목은 기존 합성 평가셋으로 효과를 즉시 판정 가능.

### 4-1. 단기 — 기존 데이터로 즉시 가능

- [ ] **스무딩 기본 채택 반영** — 현재 검증된 최적 구성(④+스무딩)을 정식 파이프라인 스크립트로 통합
- [ ] **전 지점 확장** — 현재 3개 지점(11·14·17) → 39개 전체 지점으로 학습·평가 확대, 충분한 에폭(현재 검증 10에폭)으로 재학습
- [ ] **하이브리드 스코어** — 규칙 기반 점수와 LSTM-AE 재구성 오차를 결합(가중합 또는 앙상블), 각 방식이 잡는 이상 유형이 상호보완적인지 검증
- [ ] **EVT 기반 동적 임계값** — 지점별 95% 분위수 대신 극단값 이론(POT)으로 오차 꼬리 분포를 모델링, "상위 X%" 임의 기준 제거

### 4-2. 중기 — 원본 영상/외부 데이터 재처리 필요

- [ ] **하단 중앙점(bottom-center) 재추출** — 현재 CSV는 바운딩박스 중심 기준. 호모그래피 유효성을 위해 바퀴 접지점 기준으로 원본 영상 재처리 (`trajectory_yolo8.py` 수정)
- [ ] **위성사진 대응점 기반 실측 호모그래피** — 보유 중인 `위성사진(지점)` 자료로 지점당 4개 이상 대응점을 수동 라벨링 → 실제 도로 평면 좌표 변환
  - 선행 작업: CCTV 프레임과 위성사진을 나란히 띄우고 대응점을 클릭하는 라벨링 도구 제작
- [ ] **차로폭 기반 미터 스케일** — 완전 보정 후 국내 차로폭(3.0~3.5m)으로 스케일 고정 → 오프셋을 미터, 속도를 km/h로 해석, 물리적 임계값 설정

### 4-3. 장기 — 모델·특징 고도화

- [ ] **곡선 중심선 좌표계** — 직선 PCA 축 대신 도로 곡선을 따르는 좌표계(Frenet frame)로 오프셋 계산 → 곡선 도로의 차로횡단·지그재그 탐지 개선
- [ ] **예측 기반 이상 점수** — 재구성 대신 미래 궤적 예측(seq2seq) 오차로 판정, AE 과잉일반화 회피
- [ ] **실제 이상궤적 라벨링** — 합성이 아닌 실제 CCTV의 이상 사례를 라벨링해 평가셋 신뢰도 향상
